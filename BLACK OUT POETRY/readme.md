Word Blackout Poetry Generator
A minimalist web app that transforms ordinary text into accidental poetry.
Users paste text into the app, select a generation mode, and the system randomly hides most of the words while leaving fragments visible. The remaining visible words create unexpected meanings, rhythms, and poetic structures.
Inspired by:
blackout poetry
redaction art
cut-up literature
censorship aesthetics
accidental writing systems
Features
Paste any text
Generate blackout poetry instantly
Multiple generation modes:
Sparse Mode → reveals ~5% of words
Poetry Mode → reveals ~15% of words
Chaos Mode → reveals ~50% of words
Preserves original sentence structure
Fully offline
No login
No backend/server required
Single-file HTML app
How It Works
The app:
Splits the original text into words
Randomly selects which words remain visible
Blacks out the rest
Preserves spacing and sentence flow
Each generation creates a unique result.
Installation
Download or clone the repository.
Open:
index.html
in any modern browser.

Usage
Paste text into the input box
Select a mode

Read the resulting blackout poem
